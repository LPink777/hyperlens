# 视频质检清单

## 内容与叙事

先看故事层的结论：`STORY_QC.md` 最新版本是否通过（加权平均 ≥7、单项 ≥5、无 P0），确认③ 后是否改过剧本或关键镜头，改过的有没有局部复审记录（`shots/QC.md` 的“故事复核”）。成片层的复查对照的是通过验收的那一版 `script.md`。

- 是否实现最初目标，第一镜能否让目标观众理解主题。
- 时长分配是否符合信息密度，是否存在重复镜头或无关结尾。
- 数据、日期、名称、字幕和旁白是否一致；生成画面是否被误述为真实记录。
- 人物、产品、场景和关键道具在镜头间是否保持需要的连续性。

## 全片缩略图看板（合成正式成片之前必做）

在 `project.json` 检查通过后、正式合成之前做：先出低清预览 `video_pipeline.py build <project>/project.json --preview`（多画幅时每个画幅各出一版，`--aspect` 或 `--all --preview`），再出看板：

```bash
python3 scripts/storyboard_board.py --project <project>/project.json --preview [--aspect 9:16] [--key s03,s07]
python3 scripts/storyboard_board.py output/final.mp4 --cuts-json work/timeline.json     # 已有成片 + 切点时
```

脚本在第 0 / 1 / 2 秒、每镜中点、关键镜头 25% 与 75%、每个切点（转场中间帧）、最后一帧各截一帧，出 `board.jpg`（带格号、时间、镜头、类型）和 `board_phone.jpg`（每格按手机竖屏显示宽度 360px）。交给没参与制作的审阅者按 5 个问题看：

1. 缩到手机大小，屏上字和字幕还看得清吗？
2. 界面和数据是不是真的、有来源，有没有编造？
3. 转场中间帧有没有糊、重影、主体出画、黑场？
4. 前 2 秒有没有钩子（具体的物在做事、问题或反差），而不是标题、Logo、黑场？
5. 最后一帧能不能直接当封面？

**只挑最严重的 3 个问题**，每个写清格号、第几秒、哪个镜头、怎么改；只重做和重渲这几段，不整片重来；改完重出预览和看板复查这 3 处，记进 `qc/board_<轮次>.md`。每个画幅单独出看板、单独确认。看板不代替带声音完整看一遍。

## 画面

逐个检查镜头开始、结束和转场附近，而不是只取首帧。

- 变形、闪烁、额外肢体、纹理游走、身份漂移和物理穿帮。
- 非预期黑帧、静帧、冻结、跳帧、方向错误、拉伸和错误裁切。
- 字幕、标题、Logo 是否清晰且处于安全区；竖屏尤其检查底部 UI 遮挡。
- 中文字形：无方块（豆腐字）；字幕断行无单字孤行、不越出左右边距。
- 风格、曝光、白平衡和颗粒是否突兀；需要时做轻量统一而非重度滤镜掩盖。

## 声音

- 人声是否清楚，音乐是否遮蔽语音，原声是否有突兀底噪。
- 是否存在意外静音、爆音、削波、突然变大或尾部截断。
- 音效与动作是否同步，音乐是否适用于所声称的授权范围。
- **音画同步抽查**（有配乐卡拍或音效时必做）：对照 `beats.json` / 时间表，在至少 3 个卡拍点和每个关键音效处抽帧并听，画面变化（切点、动作落定、按钮按下）与声音的偏差 ≤ 1 帧（30fps 约 33 ms）为合格，> 2 帧要修；查法见 `references/audio_qc.md`「音画同步」。
- 无音轨可以是合法艺术选择；只有用户要求或项目应有声音时才强制 `--require-audio`。
- 音频按 `references/audio_qc.md` 做两级验收（素材生成后马上做素材级，导出后做成片级，都必做），用 `scripts/audio_qc.py` 标出时间点后逐个抽听。

## 技术

`validate_video.py` 检查：文件大小、视频流、H.264、yuv420p、最短边、可选时长/尺寸/竖屏/帧率、可选音频、fast-start（按 MP4 顶层 atom 顺序）和 FFmpeg 完整解码。

- 时长允许 0.25 秒封装误差；需要精确帧数时另行检查。
- 720p、1080p、竖屏和方形输出都可接受，不应统一要求 1280 像素宽。
- 完整解码通过只代表技术可播放，不代表美术和内容通过。

## 迭代与交付

记录问题对应的镜头 ID、时间码和修改方式。只重做问题镜头，再运行项目合成和关键帧复查。交付时说明实际使用的生成后端、重要素材来源和仍未解决的问题；同时报告故事验收分数、`story_lint.py` 的黄灯及理由（贯穿物、声音转折等推荐项没做的原因）、所有 `[未实测]` 步骤，以及按 (a) 继续时标出的风险。
