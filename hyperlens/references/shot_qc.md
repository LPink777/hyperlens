# 逐镜验收（生成镜头的检验门）

适用于任何 AI 生成或外部来源的镜头（文生视频、图生视频、素材库片段），不限题材。原则：**每个镜头单独过检验门，过了才进合成**；不要等整片做完才发现某一镜坏了。

## 流程

1. **试拍**：批量生成前先挑 1–2 个最难的镜头试拍（手部/精细操作、人物转身、复杂动作、多人互动），通过后再批量。
2. **技术自检**：`python3 scripts/shot_qc.py shots/sXX.mp4 --expect "期望画面一句话" --duration N`
   - 检查分辨率、帧率、时长、黑帧、冻结帧，并输出等距抽帧拼图 `frames/qc/sXX_sheet.jpg`。
   - 输出一段可直接交给审片者（独立的视频审阅 agent）的审片提示。
3. **独立审片**：把镜头和审片提示交给一个没参与生成的审阅者（看视频的 agent），必须回答：
   - 实际发生了什么（陌生人口吻，一句话一个动作）。
   - 与预期的符合度（0–10）。
   - 下面「缺陷清单」逐项有没有、出现在第几秒。
   - 可用片段的起止秒数。
4. **判定**（见下）→ 通过 / 剪用 / 重做。
5. **记录**：在镜头表或 `shots/QC.md` 记下版本、得分、缺陷、可用区间和处理方式。

## 缺陷清单（P0 必须处理）

| 类别 | 例子 |
|---|---|
| 物体凭空出现/消失 | 工具、碎片、烟雾、人物突然冒出或消失；结果没有过程（敲石头直接出成品） |
| 解剖错误 | 多指/少指、关节反折、肢体融合进身体或背景、手部形状漂移 |
| 形变/身份漂移 | 转身、转头时脸或身体变形；同一角色前后长相不一致 |
| 动作未完成或与预期相反 | 要求“下树”实际一开始就在地上；要求“切割”只是轻碰 |
| 物理穿帮 | 穿模、漂浮、液体/火焰/烟雾行为不自然 |
| 画面文字/水印/Logo | 任何生成出来的文字、伪文字、水印 |
| 时代/语境穿帮 | 现代物品、错误服饰、可辨认的真实人物 |
| 技术问题 | 黑帧、冻结、闪烁、分辨率或帧率不符、明显压缩块 |

P1（尽量修）：符合度一般但能看懂、动作幅度太小、轻微纹理游走、风格/色调与画风锁不一致。

## 判定规则

- **通过**：符合度 ≥ 7 且无 P0。
- **剪用**：P0 只出现在片段的一部分，而剩余可用区间 ≥ 该镜所需时长的 60%（不够时可略放慢 ≤ 15% 或与相邻镜头重新分配时长）。在 `project.json` 里只用可用区间。
- **重做**：其他情况。重做时**先改提示词策略再生成**，不要原样重抽：
  - 复杂动作 → 先用图片生成锁定关键帧，再图生视频；必要时首尾帧都锁定。
  - 手部/精细操作 → 改成小幅动作（手握、缓转、光扫过）或改拍结果而非过程。
  - 人物转身/正脸 → 改拍背影、侧影、剪影、脚和手，或在转身前剪掉。
  - 多人互动 → 减少人数、拉远景别。
  - 每镜最多重做 2 次；仍不过就换镜头设计（换物、换景别）或换后端（图形/HTML/实拍素材）。
- 重做只针对该镜，不动其他已通过的镜头；保留每一版文件（`sXX_v2.mp4`）与提示词。

## 合成后复查

- 每个切点前后 0.2 秒抽帧，检查跳变、空帧和主体出画。
- 用陌生人口吻描述每一镜，需要解释才认得出的算 P0。
- 正常速度带声音完整看一遍，确认剪用的区间里没有漏掉的缺陷。

## 向用户汇报

试拍后把镜头发给用户，同时说清楚：哪里好、具体缺陷在第几秒、准备怎么处理（剪用/改策略重做），由用户决定是否继续批量。成片交付时说明哪些镜头重做过、哪些是剪用、仍有哪些小瑕疵。
