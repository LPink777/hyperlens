# 中文提示词库：代码出片 / AI 生成镜头

> 来源：opus-video-prompts（joeseesun/opus-video-prompts，**未附许可证**，提示词版权归各原作者）与 awesome-opus5-5-videos（yihui-dev，MIT，但其中提示词同样归原作者）。本文**不转载**原提示词，只总结写法规律并给出原创模板；需要看原文时打开对应仓库与原帖链接。

## 1. 写法规律（从公开案例总结）

1. **先分镜，后代码/生成**：要求先交节拍表或镜头表，确认后再做；以后只改某一镜。
2. **像导演一样给结构**：写清总时长、场景数、每个场景讲什么、画幅与帧率；给参考片/参考图胜过堆形容词；用镜头语言词汇（匹配剪辑、硬切、动态文字、一镜到底、拉远揭示）。
3. **写禁用清单**：粒子爆炸、RGB 分离、镜头光晕、霓虹辉光、回弹缓动、蓝紫渐变……模板味大多来自这些。
4. **确定性渲染**：代码出片时要求「每一帧只由时间 t 决定、提供 seek(t)」，不用 CSS 过渡和计时器。
5. **让它自己看片、自己返工**：正式渲染前抽关键帧检查重叠、拥挤、看不清；交付前用正常速度看一遍。
6. **真实素材优先**：产品截图、logo、真实数据放进项目目录，让画面用真东西。
7. **预算按多轮估**：所谓一次成型多数跑了两轮以上；长片/MV 成本可能高出短片一到两个数量级。

## 2. 九种技术路线（选型速查）

| 路线 | 擅长 | 本 skill 对应 |
|---|---|---|
| 单 HTML + Canvas/SVG/JS 逐帧 + 无头浏览器截帧 + FFmpeg | 动态图形、UI 演示、信息图 | `html_motion.md` + `scripts/html_render.py` |
| p5.js + 笔刷库 | 手绘、水彩、铅笔质感 MV | 同上（页面内用 p5 实例模式，按 t 绘制） |
| Remotion | React 工程化、参数化批量 | `remotion.md` |
| HyperFrames | GSAP 时间轴、组件库、Studio 编辑 | `html_motion.md` §5 |
| Manim | 数学/论文讲解 | 外部渲染后作为镜头导入 |
| Python 逐像素/PIL 线稿 | 线稿解说、口播转线稿 B-roll | 外部渲染后作为镜头导入 |
| Three.js/WebGL | 三维场景、程序化世界 | HTML 路线（需 GPU 时渲染会慢） |
| 操控专业软件（AE/Blender/视频模型 API） | 写实、可继续编辑的工程 | 三维/GenerateVideo 后端 |
| 剪辑已有素材 | 发布片、混剪 | 原有 `project.json` 合成 |

## 3. 原创模板（填空即用）

### 3.1 一句话起步（最短可用）
```text
做一支 {时长} 秒、{画幅} 的 {类型：发布片/科普/歌词MV} 动画，讲 {一件事}。画风：{一种媒介，如线稿/水墨/纸本插画}，色板 {3–6 个色值}。先给我 {镜头数} 镜的镜头表，确认后再做。
```

### 3.2 结构化讲解片
```text
角色：资深动态设计导演。
任务：为 {对象} 做一支 {30} 秒讲解动画，单个 HTML 页面，提供 window.__seek(t)，每帧只由 t 决定。
结构：{5} 个场景——① 观众的具体痛点（一个物在出问题）② 我们做什么 ③ 三步怎么用（同一份真实数据贯穿）④ 一个真实证据（来源：{链接/数字}）⑤ 名字与行动号召（logo 被带进来，停 2–3 秒）。
画风锁：{画风一句话}；色板 {底/墨/强调}；字体 {开源中文字体}；屏上字每镜 ≤8 字。
禁用：蓝紫渐变、霓虹辉光、粒子、全部居中、所有元素淡入上移、三卡并排。
流程：先交镜头表（时间段｜物｜动作｜镜头｜屏上字｜承接），我确认后再写代码；渲染前给我 5 张关键帧。
```

### 3.3 产品发布 · 一镜到底
```text
为 {产品} 做 {15} 秒发布片。先给三个中心画面创意（彼此核心创意不同：一个元素贯穿变形 / 一次穿越尺度的运镜 / 连锁反应），每个写钩子画面、靠什么跨过每个边界、排除了什么。
我选定后写节拍表（t｜拍｜在动的｜静止的｜承接到下一拍的东西）：镜头时长差异 ≥4 倍，至少 25% 时间静止，一段连击，硬切只用于连击和落版。
素材用产品真实界面：{截图/网址}；画出操作的手或光标，原因必须看得见。快速运动开运动模糊。
```

### 3.4 口播 → 动画 B-roll
```text
把 {口播视频} 做成新的竖屏短片：人像缩成角落圆形画中画且不挡字幕；主画面换成跟着口播内容走的动画 B-roll（讲到哪个概念就画哪个概念），画风 {线稿/纸本}，全片一套色板；原声、原字幕、时长不变。先按字幕切镜头表给我确认。
```

### 3.5 AI 视频单镜提示词（配合原 prompt_playbook.md）
```text
[风格前缀——全片逐字复用] {媒介}，{色板}，{光线}，{镜头质感/胶片颗粒}。
[本镜] 主体：{固定外观描述}；单一动作：{一个动词短语}；环境：{地点/时间/天气}；景别：{特写/中景/全景}；运镜：{缓推/横移/固定}；画面中不出现文字。
```

### 3.6 风格短片（固定画风）
```text
用「{风格卡名}」风格做一支 {30} 秒片子，讲 {题材}。先写 TREATMENT：三种结构候选与选择理由、一句话梗概与起承转合、标杆作品（学什么/不拿什么）、镜头表（景别、角度、运镜、时长、为什么）、逐秒节拍、配乐卡点图、声音设计表。先出三张用真实绘制代码画的风格帧，确认后再做全片。
```
