# 参考片拆解 → 风格说明（通用）

用户给了参考片、参考图、以前的作品或“照这个感觉做”时用。先拆解，再写 SPEC 和画风锁；没有参考就跳过本文件。
接入点：故事层 2.5（世界 + SPEC/画风锁）之前；推荐方案的“标杆作品（学什么/不拿什么）”也可以用同一套拆法。

## 1. 原则

- **学感觉，不照搬**：拿走的是可量化的规律（色彩关系、字号比、节奏、动作手感、质感），不拿人物、Logo、文案、具体构图和镜头顺序。
- **写数字，不写虚词**：禁止“高级感”“有质感”“大气”“干净”这类词单独出现；每条都要落到色号、字号比、秒数、帧数、百分比或可复现的参数。形容词→数字的换法见 `style_lock.md` 第 2 节。
- 参考是用户给的作品时，默认版权归原作者：只做内部拆解，不把原片画面放进成片。

## 2. 拆什么（每项都要有具体值）

| 项 | 写什么 | 怎么得到 |
|---|---|---|
| 色板 | 3–6 个 HEX，标出底色 / 墨色（字与结构线）/ 唯一强调色及占比；冷暖倾向 | 脚本自动量 + 人工挑选 |
| 明度与饱和度 | 暗调/中间调/亮调、对比度、饱和度高低 | 脚本自动量 |
| 字体 | 衬线/无衬线/手写/等宽、字重；**大小字号比**（例：标题字高 9% 画面高，正文 3.5%，约 2.6:1）；字距 | 看代表帧人工填 |
| 第一眼视线落点 | 每张代表帧第一眼看哪里、靠什么引导（对比、大小、强调色、留白、运动） | 看拼图人工填 |
| 节奏 | 平均 / 中位镜头时长、每分钟切换次数、是否卡拍（BPM 用 `beat_map.py` 量） | 脚本自动量 |
| 动作手感 | 干脆（快进快停）/ 滑动（匀缓）/ 回弹（过冲回位）；小元素和大元素是否不同；有无运动模糊 | 看原片人工填 |
| 画面质感 | 颗粒、锐度、景深、暗角、光源方向、材质（纸、玻璃、胶片、屏幕录制） | 看代表帧人工填 |
| 镜头语言 | 常用景别、运镜、转场方式（硬切 / 承接 / 叠化） | 看原片人工填 |

## 3. 脚本自动量的部分：`scripts/ref_analyze.py`

```bash
python3 scripts/ref_analyze.py ref/ref.mp4 --out ref/analysis            # 视频：切分、代表帧、色板、明度、草稿
python3 scripts/ref_analyze.py ref/a.jpg ref/b.png --out ref/analysis    # 参考图：只做色板和明度/饱和度
```

- 镜头切分用 ffmpeg 的 scene 分数（默认阈值 0.3，`--threshold` 调；叠化、一镜到底会被少算，以拼图复核为准）。
- 代表帧取每镜中点（最多 `--frames` 张），拼成 `<名>_board.jpg`；主色板用 k-means 算出 HEX 和占比，出 `<名>_palette.png`。
- 输出 `<名>_breakdown.json` 和 `<名>_风格说明草稿.md`；字体、视线落点、动作手感、质感、镜头语言留【待填】，由人或审阅者看拼图后填写。
- 只依赖标准库和 ffmpeg；脚本只给数字，不判断好不好看。

## 4. 输出：项目里的 `风格说明.md`

把草稿补全后存为项目根目录的 `风格说明.md`，结构：

1. 参考来源（文件 / 链接、谁给的、用途）。
2. 自动量出的数字（色板 HEX + 占比、明度、饱和度、平均镜头长度、BPM）。
3. 人工填的项（字体与字号比、视线落点、动作手感、质感、镜头语言），每项都有具体值。
4. **学什么**（3 条）/ **不拿什么**（人物、Logo、文案、具体构图……）。
5. 并入画风锁：画风一句话、色板（选定的 3–6 个 HEX 及角色）、SPEC 的 LOOK / MOTION / TIME 行怎么写。

写完并入 `style_lock.md` 的表前三行和 SPEC（`storyboard_spec.md` 第 3 节）；≥45 秒的片子在确认②里和画风锁三行一起发给用户，不另增确认点。
