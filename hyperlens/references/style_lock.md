# 画风锁（固定画风、风格短片、系列一致性）

目的：整片（以及同一账号的系列视频）看起来出自同一个美术，而不是每镜换一种画风的拼贴。

> 方法来源：Lemo-Opuscar（lemomo-ai/lemo-opuscar，MIT）的「风格卡 STYLE.md 结构 + 可改/慎改/不可改 三分法」；
> huashu-art-motion（MIT）的「表前三行画风锁、色板、禁蓝紫 AI 味」；HyperFrames（Apache-2.0）的「形容词换成数字、按媒介定义画风、默认禁用清单」。内容为改写与综合。

## 1. 表前三行（每个项目必填，写在分镜表最上方）

> 来源：故事层 2.5 写完 `world.md`（<45 秒写在 `STORY.md` 的主角与世界卡）后由它派生——“画风/色板”来自世界卡的光线与配色、品牌卡；“角色”来自主角卡的可拍方式和视觉锚点。规则不变，只是不再凭空写。≥45 秒在确认②里只发这三行和文字卡，不出图。

```text
画风：一句话写清全片唯一的画法（例：暖木色纸本插画，平涂加细铅笔线，午后侧光）
色板：3–6 个色值，写明谁是底色、谁是墨色、谁是唯一强调色及它能出现在哪
角色：无 / 只出手和背影 / 角色 ID（主角卡的一致性描述）+ 参考图或帧库路径（第 3 步后补）
```

规则：换场景可以，换画风不行；所有镜头（AI 生成、代码动画、标题卡、图表）都用同一套色板与字体。干净统一但略像幻灯片的片子，胜过花哨的拼贴。

## 2. 把形容词换成数字（写进 SPEC 的 LOOK 行）

| 客户说 | 变成 |
|---|---|
| 高级 | 一种有参数的材质：2% 颗粒的哑光纸；无缝背景上 0.55 透明度的接触阴影 |
| 现代 | 一个镜头 + 一套字体规则：30 帧的推镜、统一缓动；标题字高 9% 画面高、字距 -2% |
| 干净 | 网格与配额：12 栏、96px 边距、每镜只有一个词用强调色 |
| 有活力 | 卡拍点切、每小节换一次版式、每镜一个主动作 |
| 俏皮 | 位置/缩放用阻尼 0.45–0.6 的弹簧（不用在透明度和颜色上），姿态夸张 10–30% |
| 电影感 | 一支镜头 + 一套光：35mm 景别、左上主光、背后轮廓光、6% 暗角 |

## 3. 按「媒介」定义画风，而不是只给调色板

一个站得住的画风 = 一种媒介的规则：纸/底是什么、墨 A 负责什么（所有要读的字和结构线）、墨 B（唯一强调）一帧只给一个焦点、叠印/笔触/网点怎么出现，以及**这种媒介自己怎么动**（纸被剪开掀起、墨被印上、玻璃折射、黏土被按压）。动效来自媒介，画面就不会退化成「所有东西淡入上移」。

## 4. 风格卡模板（可复用，存为 `styles/<名字>/STYLE.md`）

只写对这个风格的**每一支片**都成立的东西，不写具体故事：

1. 本质与边界：一眼认出的 3–5 个特征；容易混淆的相邻风格及分界线。
2. 材质与渲染：媒介、纹理、图层、边缘、光；哪些效果锚定在世界里、哪些在屏幕空间。
3. 色彩逻辑：几种色相、中性底色、强调色留给什么、什么永远不上色（最多给一套示例色板）。
4. 字体与字幕：开源字体、角色（标题/字幕/小数据）、字号范围、字幕如何融入风格；阅读时长规则。
5. 运动质感：帧率与「一拍一/一拍二」、缓动家族、重量感、出现与消失方式；什么永远不动。
6. 镜头语法：一张「运镜 → 表达什么 → 适合什么时刻」的词汇表，不规定开头结尾；允许和禁止的转场。
7. 声音调色板：乐器音色、拟音材质、环境声、静默的用法、响度（约 -14 LUFS）。
8. 媒介原生招式：只有这种媒介能做的瞬间（墨晕开变成下一场、折纸变转场、网格吸附成 logo），各写 3 个不同用途。
9. 媒介陷阱及修法。
10. 工程：可复用代码/提示词片段在哪。
11. 变化空间：每支片由导演决定的部分；各给三种结构、三种开头、三种结尾，彼此远离示范片。

## 5. 改成「自己的风格」（品牌化）

把一个现成风格拆成三组再动手：
- **放心改**：配色、字体、动作快慢、声音、标志镜头；
- **一改就变味**：材质和画法、配色的逻辑、镜头语法（改之前说明代价）；
- **不能改**：风格本质（改了就是另一个风格）。

流程：一次只问一个问题且给推荐项 → 汇总「改前/改后/代价」让用户确认 → 用真实绘制代码（或真实生成）出一张并排风格帧（原版 vs 新版）→ 15–30 秒 demo 片覆盖每一处改动 → 用户点头后才固化存档。两轮仍不对就建议换底子风格。

## 6. AI 生成镜头的画风锁

- 每条提示词的风格段落**逐字复用**同一段「风格前缀」（媒介、色板、光线、镜头质感），只改主体与动作。
- 角色同理：主角卡的“一致性描述”逐字写进 `PROMPTS.md` 的 `## 角色ID` 小节，每个出现该角色的镜头都复用（`story_lint.py` 会检查）。
- 先生成并确认 1–3 张关键帧/首帧（确认④，在 2.9 通过、第 3 步后端路由之后），后续镜头一律图生视频，复用同一参考图。
- 画面里不生成文字；文字统一后期叠加。

## 7. 默认禁用清单（BANNED，除非品牌或用户参考本身就是这样）

- 深色/藏青虚空底，小元素漂在中间；
- 辉光、泛光、霓虹、镜头光晕、发光球环、装饰性漂浮粒子、彩纸爆炸；
- 蓝紫渐变、网格渐变、深紫星空、毛玻璃卡片（点名要才用，并写明理由）；
- 米白纸底 + 衬线大标题 + 斜体强调 + 「01/02」编号 + 等宽小标签 + 胶囊按钮这一整套模板味；
- 全部居中；所有元素一起淡入；每个元素都「淡入 + 上移」；字在被阅读时还在动；
- 装饰性角标、边框、HUD 读数；三张卡片一排、KPI 网格、压暗截图上叠标题；角落常驻小 logo；
- 代码画的 Q 版小人、白壳机器人、长了脸的硬币和小球。

首版出来后，把实际出现的默认套路逐一写进本片 SPEC 的 BANNED 行并修掉；清单随每支片增长。
