# 结构模板库（2.3 选结构、2.6 排节拍、2.7 写剧本时用）

8 种结构对应 `story_pipeline.md` 第三节的题材路由。每种写：骨架、时长分配参考、一个原创中文样例（只示范写法；样例里的数字都是“示意”，真做时要换成事实卡里有 `[F#]` 的真实素材）、做坏方式。
同一支片可以借用别的结构，但 2.3 的方案之间“结构、主角类型、钩子类型”至少两项不同。

## 1. 科普/历史：问题 → 常识 → 反常识 → 证据 → 新理解 → 回到观众（悬念型）

- 时长参考：问题 8% / 常识 15% / 反常识 15% / 证据 35% / 新理解 17% / 回到观众 10%。
- 样例（45 秒，“为什么冰箱里的面包反而更快变硬”）
  - 钩子：一只手把面包放进冰箱，第二天掰开，掉渣。旁白：“冷藏是为了保鲜，可它为什么更硬了？”
  - 常识：“我们以为变硬是因为变干。”
  - 但是：同样密封的两块面包，冷藏的那块先硬（贯穿物：两块面包，一冷一常温）。
  - 所以：淀粉在低温下重新结晶得更快——这才是“变硬”。[F#]
  - 新理解：冷冻会把这个过程几乎停住。[F#]
  - 回到观众：“明天吃不完的面包，放冷冻，不放冷藏。”
- 做坏方式：按年代或条目一条条列（年表味）；开头就说答案；证据只有一句“研究表明”；结尾换了一个新话题，没回答开头的问题。

## 2. 产品发布/功能演示：卡住 → 旧办法 → 产品介入 → 结果 → 下一步（结果先行型）

- 时长参考：结果先行 10% / 卡住 15% / 旧办法 15% / 介入（真实操作）35% / 结果 15% / 下一步 10%。
- 样例（30 秒，一个虚构的“会议纪要整理”功能）
  - 结果先行：一页整理好的纪要停在屏幕上，三条待办已经分配到人。
  - 卡住：用户画像“刚开完会的组长”，录音 40 分钟（示意），光标在空白文档里闪。
  - 旧办法：快进、暂停、敲字，进度条只走了一小段。
  - 介入：拖入录音，点一次按钮；界面状态从“处理中”到“完成”（真实录屏或按截图重建）。
  - 结果：待办列表里的名字被逐个高亮——回扣开头那一页。
  - 下一步：“在会议页右上角就能找到。”（入口来自真实界面）
- 做坏方式：变成功能清单（每拍一个功能，没有一个人卡住）；界面对着空气自己变化，看不见光标或手；“快 20 倍”这类没有依据的换算；没有下一步。

## 3. 广告/品牌：痛点 → 转折 → 卖点（每个附依据）→ 行动（结果先行型）

- 时长参考：痛点 25% / 转折 15% / 卖点 40% / 行动 20%。
- 样例（15 秒，虚构保温杯）
  - 痛点：早高峰地铁里，手里的咖啡洒在袖口上。
  - 转折：换成拧紧的杯盖，杯子被倒过来甩了一下。
  - 卖点：一滴没漏（依据：品牌提供的密封测试视频 [F#]）。
  - 行动：“通勤带它就够了。”落版：品牌色、口号。
- 做坏方式：用了“最好/第一/唯一”等极限词且没有依据；卖点比画面多；行动号召是空口号；品牌色值、字体和品牌卡不一致。

## 4. 教程：结果 → 步骤（操作 + 屏幕结果 + 为什么）→ 常见坑 → 再看结果（结果先行型）

- 时长参考：结果 10% / 步骤 60% / 坑 20% / 再看结果 10%。
- 样例（60 秒，“给照片批量加文件名前缀”，命令须在本机或沙箱里实测后再写）
  - 先看结果：文件夹里一排 `trip_` 开头的文件。
  - 第 1 步：操作“打开终端进入文件夹” → 屏幕结果“`ls` 列出原文件” → 为什么“先确认改的是哪一批”。
  - 第 2 步：操作“运行改名命令” → 屏幕结果“文件名变了” → 为什么“一次改完，不用逐个点”。
  - 常见坑：文件名里有空格时命令报错——实测报错原文，再给修法；没实测的坑标 `[未实测]`。
  - 再看结果：同一个文件夹，回扣开头。
- 做坏方式：只有操作没有屏幕结果；“接着/然后”连到底，没说为什么；编造没跑过的输出；常见坑放在最后一秒一闪而过。

## 5. 剧情短片：欲望 → 障碍 → 尝试失败 → 转折 → 代价 → 新状态（悬念型）

- 时长参考：欲望 10% / 障碍 15% / 尝试失败 25% / 转折 15% / 代价 20% / 新状态 15%。
- 样例（60 秒，虚构）
  - 欲望：一个小男孩想把风筝放上天给住院的奶奶看（贯穿物：一只红风筝）。
  - 障碍：楼下没有风。
  - 尝试失败：他拖着风筝跑，风筝在地上翻滚，线缠成一团。
  - 转折：他爬上天台，风来了。
  - 代价：风筝线割破了手，他没松开。
  - 新状态：病房窗外，一只红风筝停在半空；奶奶的手贴在玻璃上。
- 做坏方式：主角没有想要的东西，只是在“经历”；冲突靠旁白讲而不是动作；结尾没有新状态；关键动作（伸手、松开）在逐镜验收时被改成背影后没人复查。

## 6. 口播/解说：观点钩子 → 论点 ×3（各配证据和画面）→ 反方或误区 → 结论（悬念型；观点先行时为结果先行型）

- 时长参考：观点 10% / 论点 60% / 误区 15% / 结论 15%。
- 样例（90 秒，“早起不一定让人更高效”）
  - 观点钩子：“你不需要五点起床。”
  - 论点 1–3：作息类型有个体差异 [F#]；睡眠不足会抵消早起的时间 [F#]；高效看的是专注时段 [F#]——各配一张图示或 B-roll。
  - 误区：“成功人士都早起”是幸存者偏差的说法，点名并给出反例来源。
  - 结论：“找到你自己的专注时段，比闹钟更重要。”
- 做坏方式：三个论点其实是同一个；证据只有“有研究说”；画面一直是出镜人正面，没有字卡和 B-roll；旁白占满全片，没有停顿。

## 7. 动态图形/信息卡：一个数字或问题 → 拆开 → 对比 → 一个结论画面

- 时长参考：数字 15% / 拆开 35% / 对比 30% / 结论 20%。
- 样例（20 秒，示意数据）
  - 一个数字：屏幕中央一个大数字“8 小时”（贯穿图形：一根时间条）。
  - 拆开：时间条裂成几段，每段一种颜色，标“通勤 / 会议 / 专注 …”。
  - 对比：专注那一段被拉出来，和其他段并排，明显最短。
  - 结论画面：只剩专注那一段，变粗、发亮，停住 1 秒。
- 做坏方式：每拍都是“淡入 + 上移”的卡片；数字不来自事实卡也不标“示意”；手机上读不清（字太小、停留太短）；没有承接，像翻 PPT。

## 8. MV/氛围片：按音乐段落排“段落-意象-情绪”（情绪命题）

- 骨架：前奏（建立情绪空间）→ 主歌（意象出现）→ 副歌（情绪高点，意象变化）→ 桥段（反差：节奏或画面突然收）→ 尾奏（意象回扣，落点）。
- 样例（情绪命题“离开的那一刻”）
  - 前奏 0–8：清晨空房间，窗帘被风吹起（意象：一串钥匙放在桌上）。
  - 主歌 8–32：行李箱滚轮声，钥匙被手拿起又放下。
  - 副歌 32–56：门打开，逆光；钥匙留在桌上。
  - 桥段 56–64：画面静止，声音只剩风。
  - 尾奏 64–80：空房间，钥匙还在，窗帘落下。
- 做坏方式：画面切点和音乐段落对不上；意象每段都换，没有回扣；加了旁白解释情绪；“音乐段落”列没手工标秒数就开拍。

## 钩子库（多个方案各用不同的钩子）

| 类型 | 例句 / 画面 |
|---|---|
| 反常识问句 | “冷藏是为了保鲜，为什么面包反而更快变硬？” |
| 结果先行 | 先给一页做好的结果，再倒回去讲怎么做到 |
| 前后对比 | 左边一团乱的文件夹，右边整整齐齐 |
| 具体数字 | “每天 40 分钟（示意）花在同一件事上” |
| 局部特写谜面 | 只拍一只沾着颜料的手，不告诉是谁、在做什么 |
| “如果……” | “如果明天起所有的灯都不亮了？” |
| 冲突瞬间 | 咖啡洒出来的那 0.5 秒 |

## 故事层做坏方式（2.9 审阅者开审前对一遍）

1. **年表 / 清单**：一拍一个年代或一个功能，拍与拍之间只有“然后”。
2. **没提出问题**：开头不抛问题，结尾直接说结论，观众没有理由看下去。
3. **没有主角**：每镜换一个人或一个东西，观众跟不住；非人主角没有欲望和障碍。
4. **旁白像配图说明**：一镜一句、和镜头表同时写完；画面拍出来的又说一遍；旁白占满全片，没有呼吸。
5. **张力一条直线**：一路平铺或一路上扬，没有一次下沉（卡住、失败、反差）。
6. **结尾不回扣**：最后一句换了新话题，或喊口号。
7. **关键镜头被验收改掉**：为避开 AI 缺陷，把情绪高点（伸手、按下、转身）改成背影或结果，没回到故事层复查。
8. **事实和观点混写**：书中观点写成定论；示意数字没标“示意”；卖点没有依据。
