# 通用镜头提示词手册

## 镜头提示词结构

`主体 + 单一动作 + 环境 + 构图/景别 + 相机运动 + 光线/色彩 + 材质/风格 + 情绪 + 连续性约束`

提示词只描述当前镜头，不写整部电影的剧情梗概。不要在提示词里堆砌相互冲突的风格、时间和机位。

## 通用模板

```text
[主体及可识别特征] 在 [具体环境] 中 [一个主要动作]。
[景别与构图]，[相机运动]，[光线与色彩]，[材质和风格]。
保持 [角色/产品/场景] 外观一致，动作自然，主体始终可辨。
画面不添加文字、标志或水印。
```

“不添加文字”等约束只能降低概率，最终仍需看片；重要文字后期添加。

## 不同题材的镜头示例

### 产品广告

> 一只哑光银色无线耳机置于深灰石材台面，耳机盖缓慢打开。近景特写，相机从左向右小幅滑移，柔和顶光与窄条轮廓光，真实产品摄影，克制高级。保持耳机形状、比例和颜色一致，不添加文字或品牌标志。

### 科普示意

> 透明水滴从叶尖落下并激起细小涟漪。微距镜头，固定机位，清晨侧光，自然色彩，动作简洁清晰。保持叶片和水滴形态稳定，不添加文字。

数据、公式和步骤文字应使用图形后期，而不是依赖视频模型准确书写。

### 旅行短片

> 清晨的沿海步道，一位穿浅色外套的行人沿小路缓慢前行。中远景，相机平稳跟随，海面柔和反光，自然纪录片风格。保持人物外观和行进方向一致，不添加文字。

### 动态图形

优先不用文生视频。使用可复现图形代码定义：画布、元素层级、进入/停留/退出时间、 easing、字体、颜色和最终安全区。

## 首帧与参考资产

- 首帧负责构图，视频提示词负责动作；不要在视频提示词中重新设计一个完全不同的场景。
- 产品参考图要展示正确结构；角色参考图要包含需要保持的关键特征。
- 参考图数量不是越多越好，只提供当前镜头真正需要的资产。

## 失败后的改写顺序

1. 删除次要动作和风格形容词。
2. 缩短运动路径与镜头时长。
3. 固定相机，减少主体与镜头同时运动。
4. 改用远景、特写或静帧轻运动。
5. 换后端，不把重复生成当成万能修复。
