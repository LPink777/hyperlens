# 音频验收与混音规范（通用）

适用于所有题材、所有声音来源：TTS 旁白、真人录音、ffmpeg 合成的环境音、音乐、AI 视频镜头自带的声音、最终混音。

## 两级验收，都必做

| 级别 | 什么时候 | 查什么 | 不过怎么办 |
|---|---|---|---|
| **素材级** | 每段音频**生成或合成完马上查**，在进混音之前：每条旁白、每段环境音/音效、每段音乐、每个要保留原声的镜头音轨、每个中间混音（如 vo.wav、ambient.wav） | 全程逐窗扫描：底噪、嘶嘶声、噼啪/静电/爆音、click、削波、响度突跳、间隙里的噪声 | 只重做这一段素材（换参数、换生成方式、修滤波），过了再进混音 |
| **成片级** | 每次导出 final.mp4 之后 | 同上，加整体指标：积分响度、真峰值、削波样本数 | 按时间点回溯是哪条素材或哪一步混音造成的，修源头后重建，再查 |

素材级查过不等于成片级可以跳过：混音、ducking、loudnorm、编码都可能引入新问题，被人声遮住的瑕疵也可能在别的地方露出来。成片级查出问题时，要回到素材级定位源头，而不是在成片上打补丁。

```bash
# 素材级：单个或批量，--kind 选 vo / ambient / music / mix / auto
python3 scripts/audio_qc.py audio/vo/s01.mp3 --kind vo
python3 scripts/audio_qc.py audio/vo/*.mp3 --kind vo --out qc/audio
python3 scripts/audio_qc.py work/ambient.wav --kind ambient
# 成片级
python3 scripts/audio_qc.py output/final.mp4 --kind mix --lufs -16 --tp -1 --out output/qc
python3 scripts/audio_qc.py output/final.mp4 --kind mix --vo work/vo.wav     # 有旁白分轨时，停顿判定最准
# 只剩成片、没有分轨时的嗡声补救（先 --dry-run 看测出的单音和滤镜链）
python3 scripts/audio_qc.py output/final.mp4 --fix-hum output/final_dehum.mp4 --dry-run
python3 scripts/audio_qc.py output/final.mp4 --fix-hum output/final_dehum.mp4
```

- 嗡声检查对所有 `--kind` 默认开（`--no-hum` 关掉；素材是故意的持续音，比如音乐里的长音，就关掉并在 QC 记录写明）。停顿检查在 `mix`/`auto` 或给了 `--vo` 时运行；停顿 < 2 s 或说话 < 5 s 时跳过。
- `--fix-hum`：按测出的单音逐个陷波（`equalizer` 窄带衰减，深度按单音比主体高多少定，−6…−40 dB），先 90 Hz 高通；停顿处低频偏高时再加 120 Hz 两级高通；然后两遍线性 loudnorm，视频流直接复制。修完自动复查，还不过就 exit 2 并提示 `hyperlens:`。单音本身就是主要内容（比主体只低 < 3 dB，例如没有旁白的纯和弦铺底）时陷波会把内容一起挖掉，只能换铺底重建。这是补救，不代替修源头。

脚本会给出：采样率/声道、积分 LUFS、真峰值 dBTP、采样峰值、削波样本数，以及每个问题的**时间区间 + 类型 + 说明**，并生成全程频谱图和每个问题区间的局部频谱图；有问题时 exit 1。

**脚本不能代替耳朵。** 每个被标出的时间点都要抽听（带耳机，正常音量），并看对应频谱图确认；没标出的部分也要在成片审片时完整听一遍。把结论记到项目的 `audio/QC.md`（或 `shots/QC.md` 的音频小节）：文件、问题、时间点、原因、处理。

## 判定标准

- **必须为零/必须修**（P0）：削波样本数 > 0；真峰值 > −1 dBTP；噼啪/静电/爆音/click；成片积分响度偏离目标超过 ±1 LU；旁白间隙里有持续底噪或嘶嘶声（> −60 dBFS）；突然的响度跳变；任何听得出的数字杂音。另有两条针对“嗡嗡声”的 P0：
  - **嗡声（持续低频单音）**：1 s 汉宁窗、1 Hz 分辨率，每个频点取全片 20 分位（只留“一直在”的成分，旁白和音乐的变化部分被滤掉），在 30–500 Hz 找峰；峰（±1 Hz 三个频点之和）比 ±3…50 Hz 邻域中位折算到 100 Hz 带宽的噪声高出 ECMA-74 突出音门限 `8 + 8.33·log10(1000/f)` dB 才算单音。所有单音合计电平比主体（最响 40% 的 1 s 窗的中位）高于 **−20 dB** 判 P0（低于 −70 dBFS 的忽略）；落在 50/60 Hz 的 1–8 倍 ±1 Hz 的标为电源嗡声。依据：实测静态正弦铺底的成片为 −7.8…−0.4 dB，正常旁白/授权音乐/`bed` 生成的铺底测不到单音。
  - **停顿处铺底过响 / 低频偏高**：用旁白分轨（`--vo`，< −60 dBFS 算停顿、> −40 dBFS 算说话）或自动判定（1–4 kHz 频带每 100 ms，≥ 全片 90 分位 −15 dB 算说话、≤ 90 分位 −28 dB 算停顿）。停顿处电平只比说话段低不到 **15 dB** 判 P0（规范要求铺底比旁白低 15–20 dB）；停顿处 < 150 Hz 的电平只比说话段低不到 **25 dB** 判 P0（低频轰/嗡在停顿时最明显）。
- **要看情况**（P1）：环境音高频能量偏高（可能是设计好的风沙/海浪，也可能是嘶嘶声，听了再定）；间隙电平偏高但是呼吸声；测到单音但合计低于 −20 dB 上限（输出里的 `[提示]`）。确认是“故意的声音”就在 QC 记录里写明，否则修掉。
- 频谱图上的典型坏信号：**竖直的宽带亮条**（从低频一直到 10 kHz 以上）= 硬切脉冲/click/静电；**整片均匀的高频雾** = 嘶嘶声/噪底；**顶部被削平的波形、谐波杂乱** = 削波失真；**贯穿全片的水平细亮线**（几百 Hz 以下）= 静态正弦铺底或电源嗡声。

## 生成和混音规范（预防）

1. **AI 视频镜头的原声默认静音**（`-an`）。确要用原声，先把音轨单独导出，做素材级验收、抽听后再进混音。
2. **统一格式再混**：所有轨先 `aresample=48000`，统一声道布局（`aformat=channel_layouts=stereo`），避免混音时隐式重采样。
3. **合成噪声类音效（火、雨、静电感纹理）不要用硬开关**：`volume='gt(random(1),x)'` 加 `eval=frame` 会产生约 21 ms 的矩形门脉冲，边缘陡峭，听感是噼啪/静电，频谱上是竖直宽带亮条。要做随机脉冲，就给每个脉冲加包络（指数衰减或几毫秒的起落斜坡）、限制带宽，并把电平压低；优先用真实授权素材。
4. **增益预留 headroom**：各轨先调到合适电平（旁白峰值约 −6 dBFS 以下，铺底低于旁白 15–20 dB），`amix` 用 `normalize=0`，后面接 `alimiter=limit=0.89:level=0`（约 −1 dBFS；`level=0` 关掉自动电平，否则 alimiter 会把整体电平拉回 0 dBFS）兜底，再做响度归一。`music.volume` 不要 > 1。
5. **响度用 loudnorm 两遍法**：第一遍 `loudnorm=I=-16:TP=-1.5:LRA=11:print_format=json` 量出 measured_*，第二遍带 `measured_I/TP/LRA/thresh/offset` 和 `linear=true` 归一。单遍动态模式会在安静段把增益拉高，把噪底和铺底里的瑕疵一起放大。
6. **旁白每段首尾加淡入淡出**（各 10–30 ms，`afade`），段落拼接处不要硬接，防止 click。
7. **环境音循环或拼接**用 `acrossfade`（≥ 0.5 s），不要直接 concat；段与段的电平变化用包络过渡，不要用 `between()` 这类阶跃开关直接切。
8. **ducking**（旁白压低铺底）阈值和释放时间要合理（attack 20–50 ms、release 300–800 ms），避免抽吸感。`video_pipeline.py` 有音乐时默认开侧链压缩（threshold 0.02、ratio 6、attack 20 ms、release 400 ms）。
11. **铺底/音乐先高通 ≥ 120 Hz**（`video_pipeline.py` 默认 150 Hz 两级）。TTS 旁白基频大多在 100–250 Hz 以上，150 Hz 以下的铺底能量对“氛围”几乎没贡献，却是耳机里“嗡/轰”的主要来源。
12. **不要用静态正弦（`sine`、`aevalsrc` 叠和弦）做持续铺底**：恒定音高、恒定电平的单音在旁白停顿处会被听成“嗡嗡声”，混音和陷波都救不干净。没有授权音乐就默认无音乐；要铺底用 `video_pipeline.py bed`（带通粉噪 + 7/11/13 s 慢速起伏，无稳态音，150 Hz 以下已切，RMS −30 dBFS），生成后照样跑素材级验收。
9. 导出用 AAC 192 kbps 以上，48 kHz。
10. 导出后**必须**跑成片级 `audio_qc.py`，并抽听所有被标出的时间点。

## 音画同步（有配乐卡拍或音效时必做）

1. **同一套时间点**：配乐先用 `scripts/beat_map.py analyze` 量出 `beats.json`；切镜头、音效触发、画面变化都从同一份时间表取值（HTML 合成里，音效的触发时间和 `__seek(t)` 用的关键帧时间来自同一个 JSON，不要各写一遍常数）。
2. **切点对齐**：`beat_map.py snap beats.json --project project.json`（或 `--cuts`）报告每个切点离最近拍点的偏差和建议时长；偏差 > `--max-shift` 的标“需人工”，换拍、改镜头时长或在 QC 记录里写明为什么不卡。
3. **合成后抽查**：成片里至少抽 3 个卡拍点 + 每个关键音效（按钮声、撞击、转场声）：用 `ffmpeg -ss <t-0.1> -t 0.2` 逐帧看画面变化落在哪一帧，同时听或看局部波形。偏差 ≤ 1 帧合格，> 2 帧要修（常见原因：镜头时长被四舍五入到帧、音效文件头有静音、拼接时累计误差、编码器延迟）。
4. 结果记进 `audio/QC.md`（或 `qc/` 下）：时间点、画面帧、声音位置、偏差、处理。

## 示例案例（仅供参考，不是规则）

某 90 秒纪录片成片，用户反馈“1 分 10 秒开始有杂音”。

- **定位**：成片级 `audio_qc.py` 标出两个区间的“持续型噼啪”；回到素材级，旁白（14 条 + 合轨）全部通过，环境音 `ambient.wav` 在同样两个区间同时报“噼啪/静电”和“高频异常”（高频占比约 40%，其余时段约 0%），频谱图上是整齐的竖直宽带亮条。
- **根因**：环境音里的“篝火噼啪”是用白噪声加 `volume='…*gt(random(1),0.88)*0.9':eval=frame` 做的随机硬开关，每个脉冲是约 21 ms 的矩形门，边缘陡峭，峰值接近 −1.5 dBFS；只在有火的镜头时段打开，所以从那个镜头开始突然出现。另一个有火的镜头里也有同样问题，只是被旁白遮住，听起来不明显。
- **教训**：① 合成音效不要用硬开关的随机门；② 环境音生成后要先做素材级验收，这个问题在混音前就能被发现；③ 成片级检查要覆盖全片，同一根因可能在多处出现。

**案例 2：解说片背景“嗡嗡嗡”**

某 90 秒科普解说片（TTS 旁白 + 铺底），用户反馈“背景音老是有嗡嗡嗡的噪音”。下面数据来自按该片做法复现的同长度工程（同样的 TTS 旁白 + 正弦和弦铺底、volume 2.5）。

- **定位**：成片级 `audio_qc.py --kind mix` 报 P0“嗡声”（110 Hz、165 Hz 稳态单音，合计比主体 −7.8 dB）、“停顿处铺底过响”（停顿处只比说话段低 4.5 dB）、“停顿处低频偏高”（< 150 Hz 只低 6.7 dB）。回到素材级，旁白全部通过，铺底 `tone-bed.wav` 本身就是 110/164.8/220/329.6 Hz 正弦叠成的恒定和弦。
- **根因**：① SKILL 的选择卡和使用权条款写着“ffmpeg 生成的简单音调铺底”，于是用 `sine` 叠了和弦当铺底；② `music.volume` 填了 2.5（放大），铺底在停顿处几乎和旁白一样响；③ 旧合成链音乐不高通、不避让、没有限幅，响度用单遍动态 loudnorm，停顿时增益被拉高，把嗡声一起放大；④ 旧 `audio_qc.py` 不查低频单音，mix 模式也不查停顿处电平，所以没拦住。
- **修复与实测**：同一条旁白、同一画面，只换新合成链（高通 150 Hz + 侧链避让 + alimiter + 两遍线性 loudnorm）：单音消失，停顿处 −23.4 → −30.2 dBFS，但铺底仍只比说话段低 10.8 dB，还是 P0；再把铺底换成 `video_pipeline.py bed` 生成、`volume` 用默认 0.25：停顿处 −35.6 dBFS（比说话段低 16.0 dB），停顿处 < 150 Hz −66.0 dBFS（低 46.4 dB），全部通过，积分 −16.0 LUFS、真峰值 −2.2 dBTP，说话段电平 −18.9 → −19.6 dBFS。
- **教训**：① 没有授权音乐就默认无音乐，不要用正弦和弦铺底；② 铺底先高通、再避让、`volume` 不放大；③ 成片验收要查嗡声和停顿电平，听的时候专门听旁白停顿处。
