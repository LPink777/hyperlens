# STORYLINES.md（2.3）

推荐方案 1。结构、主角类型、钩子类型三项都不相同。

## 方案 1（推荐）：手印与一个并不存在的故事

- logline：一个会讲故事的智人想让陌生人留下，硬拼留不住；TA 讲了一件并不存在的事，陌生人才把红手印按在同一面墙上。
- 结构模板：问题 → 反常识 → 硬拼失败 → 转折（虚构）→ 新理解，并回到今天的纸
- 钩子画面 + 第一句：一只手按上岩壁，不打年代字幕。「后来只剩我们。为什么？」
- 主角类型：虚构的真人角色（只拍手、背影、剪影）
- 冲突：会打猎的不止 TA 这一群，力气解决不了「陌生人为什么留下」
- 转折：掌心的赭红对着火，讲了一件岩壁上还不存在的事
- 结尾回扣：同一只红，按到今天的一张纸上
- 画风一行：洞穴火光，赭红手印是唯一高饱和颜色
- 声音一行：散开时风声切断，讲故事时只留火
- 可拍性风险：手部是关键镜头。不拍正脸、不拍精细对掌，按之前改成「掌心按壁、剪影靠拢」
- 推荐理由：观众问题要到结尾才回答。手印能把「一起相信」拍成动作，而不是年表。
- 标杆：赫拉利公开演讲里「先抛一个问题，再给书中观点」的讲法。学什么：用一个问题串起论点，观点归作者。不拿什么：幻灯片、金句原文、他口头的具体比喻句子。

## 方案 2：开头就给答案

- logline：第一句就说「一起相信让陌生人合作」，后面只用手印把这句话演一遍。
- 结构模板：结果先行，而不是悬念
- 钩子画面 + 第一句：满墙手印。「陌生人能合作，是因为一起相信。」
- 主角类型：拟人化的「故事」本身（一粒赭红从嘴边飞到墙上）
- 冲突：红粒一度熄灭
- 转折：红粒重新落到许多掌心
- 结尾回扣：红粒落在纸币上
- 画风一行：赭红粒在黑底上运动，近乎动态图形
- 声音一行：几乎无对白，只有火
- 可拍性风险：中。抽象粒要靠 HTML 才稳，和本片选定的 AI 实拍感不一致

## 方案 3：只跟人群，不跟讲故事的人

- logline：一座洞穴里的人群想活过冬天，没有单个主角；手印是群体自己的决定。
- 结构模板：从物证倒推（先给满墙手印，再倒回空墙）
- 钩子画面 + 第一句：特写一枚看不懂的手印，第一句不抛问题
- 主角类型：群体
- 冲突：墙还是空的时候，人群是散的
- 转折：第一枚手印出现
- 结尾回扣：镜头从手印拉开，墙上已经满了
- 画风一行：同一面岩壁，只改手印的数量
- 声音一行：人群脚步由疏到密
- 可拍性风险：高。多人互动是 AI 视频的难项，方案 1 用剪影和依次按手避开它
