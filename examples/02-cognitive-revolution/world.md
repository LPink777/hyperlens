## 主角卡

### 角色：C1

- ID / 类型：C1 / 真人角色（虚构）
- 身份：一位讲故事的智人，没有历史人名
- 欲望（想要什么）：让互不相识的人留在同一堆火边
- 障碍（被什么挡住）：硬拼和打猎不能回答「为什么留下」
- 转变（开头____，结尾____）：开头手按在空墙上，结尾同一只红按在纸上
- 视觉锚点：掌心和指腹的赭红；只拍手、前臂、背影、篝火剪影
- 一致性描述：深褐皮肤的手与前臂，掌心和指腹沾着未干的赭红；只拍手、前臂、背影和篝火剪影，不拍正脸；岩壁暖灰褐，火光从画面左侧来。
- 可拍方式：只拍手和背影

不设 C2。靠拢的陌生人用同一套剪影规则，不另给会漂移的脸。

## 贯穿物

- 是什么：红手印
- 钩子时的意义 → 中点时的意义 → 结尾时的意义：一个人按在空墙上 → 讲故事的人掌心对着火，红还只在一只手上 → 许多手印之后，同一枚红留在今天的纸上
